# ABSA NextGen Wealth Studio – First Five Years (Exam Submission)

## Overview
A React (Vite) prototype for a digital companion web app aimed at high-earning young professionals in South Africa. Includes Money Snapshot, Strategy Tracks, Simulation Lab, Learn hub, Profile, and a demo login with dark mode.

## Requirements
- Node.js (LTS recommended)
- npm
